# Pet_projects
[__Анализ разработки инженерных решений для поддержания безопасности полетов гражданских воздушных судов.__](Engineering Solutions/Разработка инженерных решений.ipynb) - проект-исследование факторов, влияющих на процессы работы инженерного центра, занимающегося разработкой нестандартных ремонтов и модификаций гражданских самолётов. Особое внимание в проекте уделено отменённым заказам, которые влекут за собой финансовые издержки, а также эффективности планирования трудозатрат на разработку инженерных решений. _Стек: Pandas, Matplotlib, Seaborn._
