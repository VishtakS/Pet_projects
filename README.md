Собственные проекты

[__Engineering_solutions__](Engineering_solutions/Engineering_solutions_analysis.ipynb) - __Анализ работы инженерного центра__ - проект-исследование факторов, влияющих на процессы работы авиационного инженерного центра, занимающегося разработкой нестандартных ремонтов и модификаций гражданских самолётов по запросу заказчиков. 

Особое внимание в проекте уделено запросам, отменённым впоследствии заказчиками, поскольку такие отмены влекут за собой финансовые издержки. В процессе проведённого анализа выявлены основные признаки отменённых запросов.

Кроме того, проведен анализ планируемых и фактических трудозатрат на разработку инженерных решений и дана оценка эффективности планирования трудоёмкости. 

_Стек: Pandas, Matplotlib, Seaborn._
