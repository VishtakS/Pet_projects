Собственные проекты

[__Engineering_solutions__](Engineering_solutions/Engineering_solutions_analysis.ipynb) - __Анализ работы инженерного центра__- проект-исследование факторов, влияющих на процессы работы инженерного центра, занимающегося разработкой нестандартных ремонтов и модификаций гражданских самолётов. Особое внимание в проекте уделено запросам, отменённым впоследствии заказчиками, поскольку такие отмены влекут за собой финансовые издержки. Кроме того, проведена оценка эффективности планирования трудозатрат на разработку инженерных решений. _Стек: Pandas, Matplotlib, Seaborn._
